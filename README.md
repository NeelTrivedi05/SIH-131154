## What This Is

A physics-grounded **Advisory Decision Support System** and Digital Twin for microgrid operations at India's Antarctic research stations (**Maitri** 70°45′S and **Bharati** 69°24′S). It combines:
1. **Machine Learning Load Forecaster**: Autoregressive Ridge model (`scikit-learn`) fitted on synthetic polar load series with train/test split. Evaluated at **1.75 kW MAE** vs. **2.96 kW 24h-persistence baseline** (40.9% error reduction).
2. **Advisory Dispatch Engine**: Recommends battery pre-charge and genset scheduling while enforcing mechanical anti-wet-stacking protection (55% continuous loading clamp).
3. **Dynamic 3-Tier Load Shedding**: Evaluates unmet demand dynamically across Tier 1 (Life Support: 65%), Tier 2 (Living Quarters: 25%), and Tier 3 (Scientific Equipment: 10%).
4. **Physical Wind Storm Protection**: Realistic 25 m/s turbine furling cut-out (blades feather to prevent shear damage during Antarctic blizzards).
5. **Interactive Telemetry Console**: High-density React + Vite dashboard with 1-click hourly schedule CSV export.

> [!IMPORTANT]
> **Honest Scope & Demonstration Integrity**:
> - All sensor feeds are generated by a physics-calibrated polar station simulator (not connected to live classified NCPOR station hardware).
> - The system operates strictly as **Advisory Decision Support** with human-in-the-loop oversight, not unverified autonomous closed-loop control.
> - Savings are compared against a standard uncoordinated rule-based policy (not naive diesel-only) and reported as estimated seasonal ranges (SIMULATED, ASSUMED INPUTS).

## How to Run (Under 3 Minutes)

### Prerequisites
- Python 3.10+
- Node.js 18+ (for frontend development)

### Quickstart

#### 1. Backend (FastAPI + Scikit-Learn)
```bash
cd backend
pip install -r requirements.txt
python main.py
```
*API running at: `http://localhost:8000` (Swagger docs at `/docs`)*

#### 2. Frontend (React + Vite)
```bash
cd frontend
npm install
npm run dev
```
*Dashboard running at: `http://localhost:5173` (or served directly via FastAPI at `http://localhost:8000` from `frontend/dist`)*
